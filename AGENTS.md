# Instructions projet

- Après toute modification validée dans le dépôt, faire systématiquement un commit puis un push sur la branche courante, sauf demande explicite contraire de l'utilisateur ou blocage technique.
- Avant de commit, vérifier l'état Git et ne pas inclure de changements sans rapport avec la tâche.
- Après le push, préciser ce qui est réellement en ligne. Distinguer le frontend GitHub Pages des éléments qui nécessitent une action séparée, notamment le déploiement Apps Script et la réimportation de blueprints Make.
