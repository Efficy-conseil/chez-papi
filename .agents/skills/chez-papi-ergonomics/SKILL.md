# Chez Papi Ergonomics

## Focus

Improve the staff workflow: receive a demand, qualify it, follow up, prepare/send quote, confirm event, and find past information quickly.

## Read as needed

- `.agents/project/ux-guidelines.md` for UI rules.
- `.agents/project/data-contract.md` for statuses and fields.

## Heuristics

- A user should never wonder which status is true for the same demand.
- A user should never lose a date, contact, status or follow-up note because a table is too narrow.
- A status change should be reflected consistently in all views.
- Search/filter controls should not make the table harder to use.
- Prefer reducing clicks for repeated operations over adding explanatory text.

## Output for ergonomics reviews

Give findings in order of operational impact, then the minimal UI/data change to fix each issue.
