# Chez Papi UX Design

## Start here

Read `.agents/project/ux-guidelines.md`.

## Design posture

This is an operational dashboard for a caterer, not a marketing site. Optimize for fast scanning, clear statuses, and low-friction daily use.

## Checklist

- Date, client, status, contact and venue remain visible or reachable.
- Tables have stable column widths and visible scroll affordances when needed.
- Mobile views keep actions tappable and text legible.
- Palette and typography stay consistent with the existing brand.
- Avoid decorative redesigns that reduce information density.

## Verification

For UI-heavy changes, inspect desktop and mobile layouts when feasible. If browser verification is unavailable, state that limitation and verify the CSS/HTML diff carefully.
