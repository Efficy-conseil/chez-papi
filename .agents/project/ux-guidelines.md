# Guidelines UX/UI

## Priorités

1. Les champs critiques doivent toujours rester visibles ou accessibles : date, client, statut, contact, lieu.
2. Les tableaux larges doivent utiliser un scroll horizontal visible, idéalement en haut et en bas pour l'historique.
3. Les statuts doivent rester cohérents entre compteurs, accueil, pipeline, agenda et historique.
4. Le dashboard est un outil opérationnel : dense, lisible, rapide à scanner.

## Style

- Respecter la palette existante : crème, brun, or, vert, terracotta.
- Éviter les effets décoratifs gratuits.
- Garder les cartes pour des blocs d'information réels, pas pour chaque section imbriquée.
- Préserver les contrastes et les tailles de texte dans les tableaux.
- Les boutons d'action doivent rester sobres et explicites.

## Tableaux

- Éviter les ellipses sur les champs clés si un scroll horizontal est possible.
- Donner des largeurs stables aux colonnes.
- Garder les menus de statut non tronqués.
- Ajouter un `title` sur les cellules tronquées.
- En mobile, préférer un scroll clair à une compression illisible.

## PWA mobile

- Vérifier les vues Accueil, Demandes en cours, Confirmés, Agenda, Historique.
- Ne pas masquer une action essentielle derrière un hover.
- Les éléments cliquables doivent garder une cible confortable.
